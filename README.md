# ankush-portfolio

Personal portfolio showcasing graphic design, video editing, motion graphics and UI/UX projects.

This repository has been initialized with a complete Vite + React + TypeScript starter for a creative portfolio. It includes a 3D cinematic hero using three.js (react-three-fiber) with a static fallback, a responsive project gallery, case studies, About, Services and Contact sections styled with a dark chrome theme and lime accents.

Local development

1. Install dependencies

```bash
npm install
```

2. Run dev server

```bash
npm run dev
```

3. Build for production

```bash
npm run build
```

Notes & placeholders

- Social links, project images, and contact email are placeholders. Replace them in src/components/About.tsx and src/components/Contact.tsx.
- The hero uses a procedural three.js torus-knot; replace with glTF or actual 3D assets in src/components/Hero3D.tsx for a premium look.
